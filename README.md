# Tauriisland

**Windows 桌面「灵动岛」**

把正在播放的音乐、歌词、日历、日程、天气与系统通知，收进屏幕顶部一颗可展开的胶囊里。

## 它是什么

一颗常驻屏幕顶部的胶囊，鼠标移上去会展开，把当前该看的信息一次性摆出来。用系统媒体接口（SMTC）读正在播放的内容，用在线曲库补歌词与封面，用本机系统文件读通知，日程则完全存在本地 —— **不注入、不挂钩、不读进程内存**。

四种状态：

| 状态 | 出现方式 | 显示 |
|---|---|---|
| 失焦（minimal） | 默认 | 时间 / 天气，或封面 + 歌名 + 当前歌词 |
| 悬浮（medium） | 鼠标移入 | 时间、天气、音乐三页，可滚轮切换 |
| 展开（expanded） | 点击或稍作停留 | 音乐详情 / 日历 / 日程 / 通知四页 |
| 设置（maximal） | 在展开态继续下滚 | 完整设置面板 |

全屏看视频、放映 PPT 时胶囊自动隐藏，退出全屏自动回来（默认开启，隐藏动画三选一）。

## 功能

**音乐**
- 从系统媒体接口采集曲目、歌手、专辑、封面、播放状态与进度，**跟随进度条拖动**
- 上一首 / 播放暂停 / 下一首；进度条可直接拖动跳转
- 展开态封面取主色作为光晕与进度条配色，三种状态取色同源
- 播放器无时间线时（部分播放器不上报进度）自动降级为本地时钟外推，进度条不会冻在 0

**歌词**
- 多源级联，命中即用：本地接口 → 在线曲库 → 兜底，任一环失败都静默回落
- 支持**逐字（卡拉OK）高亮**，来自歌词源自带的逐字时间轴
- 展开态显示 5 行，当前行高亮、上下行渐隐；悬浮态显示单句
- 外部源的曲目会与系统正在播放的曲目做身份核对，**不匹配就丢弃**，不会显示别人的歌词

**日历**
- 公历 + 农历、节气、法定节假日与调休（含"休/班"角标）
- 左侧通高日期块：星期、大号日号、农历、节日、干支、第 N 周 · 年内第 N 天；当天有日程时这块会自动让位，下方列出日程
- 有日程的日子在格子上打点（最多 3 个）；**双击某个格子直接跳到日程页的那一天**
- 自绘年月下拉，支持前后翻月与「回到今天」

**日程**
- 本地存储、可建可改：标题、起止时间（支持跨天与全天）、地点、备注、重复、提醒、是否响铃
- 重复规则支持每天 / 每周 / 每月 / 每年 + 间隔，按次数或日期截止；**单个重复日程可以「只改这一次」或「只停这一次」**，其余实例不受影响
- 提醒时间可自定义：提前 1-60 分钟 / 1-24 小时 / 1-30 天，或准时
- 到点后发系统通知 + 在岛上弹提醒卡（展开态直接显示，非展开态短暂展开），可选同时响铃（最长 30 秒自动停，点岛或按 `Alt+C` 立即停）
- **导入 `.ics`**：右上角导入按钮 → 解析后先预览「新增 N 条 / 更新 M 条」→ 确认才写入；按 `UID` 合并，重复的日程会更新而不是堆两条
- 日程页按日期分组，默认从今天起 7 天，滚轮滚动（滚到头才翻页）

**天气**
- 当前天气与预报，支持自动定位或手动指定城市，15 分钟缓存

**通知**
- 读取 Windows 通知中心（解析本机通知数据库）并列表展示
- 新通知到达时短暂展开胶囊提醒，**悬停时不自动收起**；可单独关闭提醒只留列表
- 可配置"不读取的应用"黑名单，把不想看到的应用排除掉
- 可整体关闭**系统通知推送**（关掉后仍会在岛内提醒，只是不再向 Windows 通知中心发）
- 可发送测试通知（用于确认提醒链路是否正常）
- 长文本可点击展开全文；本轮"清除"只影响列表显示，**不会删除系统通知中心里的通知**

**声音**
- 通知音与闹钟音分开选择，内置 4 + 4 个音色，可试听
- **可自定义音频**：选本地文件加入音效库（通知/闹钟各自归类），同一份可命名、试听、随时删除，最多 12 条
- 自定义音频本体存在独立的 `sounds.json`，不塞进设置文件

**设置**
- 位置：悬浮胶囊 / 贴边挂角，靠左·居中·靠右，水平与垂直微调
- 外观：深色 / 浅色主题、圆角、透明度、各状态宽度；语言可跟随系统或手动指定中/英
- 交互：动效速度三挡（慢 / 正常 / 快）；全屏隐藏开关与隐藏动画（淡出 / 滑出 / 两者兼有）
- 快捷键：退出、显示/隐藏岛，可自行改键；键被别的程序占用时会显示红条提示
- 歌曲：歌词来源与信任策略、本地歌词接口地址与超时
- 通知：开关、轮询、最大条数、提醒时长、黑名单、系统通知推送、音效
- 诊断：外部数据源与播放控制通道的最近一次状态，便于排查"为什么没生效"

## 安装

到 [Releases](https://github.com/shanyue16/Tauriisland/releases/latest) 下载 `Tauriisland_<版本>_x64-setup.exe` 直接安装。

需要 **WebView2 运行时** —— Windows 11 已内置；Windows 10 通常已随 Edge 一并安装，若提示缺失可从 [Microsoft 官网](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。

> 目前只提供 NSIS 安装包（不出 MSI）。

## 从源码构建

**前置要求**

- Windows 10 / 11（x64）
- [Node.js](https://nodejs.org/) 18 或更高（推荐 LTS）
- [Rust](https://rustup.rs/) 稳定版工具链，目标为 MSVC
- Visual Studio Build Tools 的「使用 C++ 的桌面开发」工作负载（Rust 链接器需要）
- WebView2 运行时

**开发**

```bash
npm install
npm run tauri dev
```

**检查**

```bash
npx tsc --noEmit                 # 前端类型检查（已开 noUnusedLocals/Parameters）
cd src-tauri && cargo check      # 后端类型检查
```

**打包**

```bash
npm run tauri build
```

产物在 `src-tauri/target/release/bundle/nsis/`。

> 首次打包会联网下载 NSIS 工具链（含哈希校验），网络不通会在这里失败。

## 使用

- **移入**胶囊展开到悬浮态；**移出**自动收起
- **滚轮**：在悬浮/展开态翻页；翻到最后一页继续下滚进入设置，在设置页滚到顶继续上滚返回
- **方向键**：悬浮/展开态内翻页（设置页不响应）
- **Esc**：退出当前展开态
- **拖动进度条**：跳转播放位置（松手才提交，避免拖动过程中反复请求）
- **双击日历格子**：跳到日程页并定位到那一天
- **日程页**：右上角 `+` 新建，点任意一行编辑（重复日程会让你选「仅此次」还是「整个系列」），右上角导入图标读 `.ics`
- **全局快捷键**：`Alt+Z` 退出应用，`Alt+C` 显示/隐藏胶囊（默认值，可在设置里改）

## 数据与隐私

所有外部请求都是**直接访问公开接口或本机服务**，不经过任何自建服务器，也没有任何遥测或统计上报。应用持有的网络白名单是封闭的，只有以下域名/端口可被访问：

| 用途 | 目标 |
|---|---|
| 天气 / 日历 / 农历 | `uapis.cn` |
| 歌词主源与兜底 | `lrclib.net`、`music.163.com`、`c.y.qq.com` 等、`lyrics.kugou.com` |
| 封面兜底 | `itunes.apple.com`、`imge.kugou.com` |
| 本机播放器数据源（可选） | `127.0.0.1` 的 32109 / 32107 / 9863 / 8765 |

发送系统通知走系统 API，不经网络。

**本地数据都在 `%APPDATA%\com.tauriisland.app\`**（Roaming，不是 Local）：

| 文件 | 内容 |
|---|---|
| `settings.json` | 全部设置项（几百字节，不含音频本体） |
| `sounds.json` | 自定义音效的音频数据（只在添加过自定义音效后存在） |
| `schedule.json` | 全部日程与重复规则；`.ics` 导入的内容也只进这里 |

删掉这三个文件即恢复到出默认状态（下次启动自动重建）。

## 可选：本机播放器数据源

下面这些是**独立的第三方程序**，装不装都能正常使用本应用 —— 没装或没启动时，歌词会自动回落到在线曲库，控制仍走系统媒体接口。

| 端口 | 提供者 | 作用 |
|---|---|---|
| 32109 / 32107 | Folia | 本地歌词接口；Stage API 提供播放进度与控制 |
| 9863 | Now Playing 服务 | 部分播放器的歌曲与歌词信息 |

它们需要各自在本机安装并开启接口，本应用**只作为客户端去读**，不安装、不守护、不拉起这些进程。

## 已知限制

- **仅支持 Windows**：核心依赖系统媒体接口（WinRT）、Windows 通知数据库与 Win32 全屏检测
- **酷狗不上报时间线**：系统媒体接口对它拿不到进度与时长，此时使用外部时长 + 本地时钟外推，**拖动进度条无法被感知**（这是播放器侧的限制，不是应用能修的）
- **逐字歌词取决于歌词源**：只有自带逐字时间轴的歌词才有逐字高亮，行级 LRC 只有整行高亮
- **通知正文可能不完整**：Windows 通知中心里存的就是发送方推送时的那份文本，部分应用（如 QQ）在推送前就已截断，应用与系统通知中心显示的内容逐字一致，无可补全
- **`.ics` 支持的是子集**：重复规则只解析每天/每周/每月/每年 + 间隔、次数/截止、星期与几号；`FREQ=HOURLY` 等会退化为单次并在导入预览里给出警告；带 `TZID` 的时间按本机时区理解（不联网查时区库，预览里会提示）
- **提醒的补发窗口有限**：应用没在运行时错过的提醒不会补发（只补最近 30 分钟内到点的），避免开一次机弹一堆历史提醒
- 首次运行若未播放任何音频，音乐页会显示空态

## 项目结构

```
src/                     前端（React + TypeScript）
  components/            岛本体、四态内容、设置面板与各子面板
    schedule/            日程编辑弹窗
  pages/                 音乐 / 日历 / 日程 / 天气 / 通知 / 时间页
  hooks/                 音乐、通知、封面取色、天气、拖动跳转、动效方向等
  services/              外部接口：歌词多源级联、播放源、天气、通知、播放控制、
                         .ics 解析、提醒调度、音效播放
  stores/                设置/日程/自定义音效持久化（逐字段校验，音频与设置分文件）
  utils/                 动效、滚动、页面路由、LRC 解析、重复规则展开、取色、portal 主题
src-tauri/               后端（Rust）
  src/smtc.rs            系统媒体接口采集与控制
  src/notifications.rs   通知数据库解析
  src/fullscreen.rs      全屏检测与自动隐藏
  src/hotkeys.rs         全局快捷键（RegisterHotKey）
  capabilities/          网络与权限白名单
public/sounds/           内置通知音与闹钟音
docs/                    设计与计划文档
```
