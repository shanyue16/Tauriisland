## 1. 项目概述

### 1.1 是什么

一个运行在 Windows 桌面顶部的灵动岛（Dynamic Island）应用。参考 Apple 的 Dynamic Island 设计和开源项目 [eIsland](https://github.com/silenthim18303/eIsland)，提供悬浮胶囊和贴边挂角两种形态，通过悬停/滚轮/点击等手势展示不同页面，聚合时间、通知、音乐播放、系统状态等信息。

### 1.2 核心价值

- **非侵入式信息聚合**：常驻屏幕顶部，不抢焦点，需要时展开
- **手势交互**：悬停展开、滚轮翻页、失焦收起，一套手势通吃
- **可高度定制**：两种岛样式、圆角可调、透明度可调、水平位置可调、后续支持主题/自定义背景
- **轻量常驻**：资源占用低（目标内存 < 60MB），支持开机自启

### 1.3 目标平台

- **主要**：Windows 10 2004+、Windows 11
- **次要（留后路）**：macOS、Linux（Tauri 天然支持，前端代码无需改动）

### 1.4 参考项目

| 项目 | 说明 |
|------|------|
| [eIsland](https://github.com/silenthim18303/eIsland) | Electron + React + TS 实现的 Windows 灵动岛，功能最完整。本项目参考其页面设计、交互模式、功能规划，但技术栈换为 Tauri 以获得更好的资源占用。 |

## 2. 技术架构

### 2.1 技术栈选择

**Tauri + React + TypeScript + (可选 Python sidecar)**

| 层 | 技术 | 职责 |
|----|------|------|
| 应用外壳 | Tauri 2.x (Rust) | 创建透明无边框窗口、置顶屏幕顶部、窗口动画、点击穿透、系统托盘 |
| 前端 UI | React 19 + TypeScript + Tailwind CSS 4 | 灵动岛渲染、CSS 动画、设置面板、状态管理 |
| 前端构建 | Vite | 开发服务器 + 生产构建 |
| 后端（可选） | Python 3 (sidecar 进程) | 系统信息采集（电量/CPU/网络）、音乐播放器状态读取、系统通知监听 |
| 前后端通信 | HTTP JSON / WebSocket | 前端主动拉取 / 后端主动推送 |
| 配置持久化 | Tauri Store 插件 | 用户设置（样式、圆角、透明度、位置等） |

### 2.2 为什么选 Tauri 而不是 Electron

| 对比项 | Electron | Tauri |
|--------|----------|-------|
| 安装包体积 | 150–300MB | 3–10MB |
| 运行时内存 | 200–500MB | 30–80MB |
| 启动速度 | ~2-3s | <1s |
| 渲染引擎 | 内嵌 Chromium | 系统 WebView2 |
| 后端语言 | Node.js | Rust（也可选 Python sidecar） |
| 跨平台 | ✅ Win/macOS/Linux | ✅ Win/macOS/Linux |

灵动岛需要**常驻后台**，内存占用直接影响体验。Tauri 体积小、内存低、启动快，是桌面悬浮窗类应用的最优解。

## 3. UI 设计

### 3.1 岛的两种样式

#### 样式 A · 悬浮胶囊

```
    ┌─────────────────────┐
    │    10:06   周一       │  ← 四周完整圆角 (border-radius: 50%)
    └─────────────────────┘
         ↑ 距屏幕顶部有 8px 间隙，居中悬浮
```

- 四周 `border-radius` 完全由设置面板的圆角滑块控制（0-30px）
- 距离屏幕顶部有 8px 间隙
- 水平位置：靠左 / 居中 / 靠右

#### 样式 B · 贴边挂角

```
╔═══════════════════════════╗ ← 上边缘紧贴屏幕顶部，与屏幕顶端齐平
║   10:06      周一          ║
╚═══════════════════════════╝ ← 仅下方两个圆角
        ↑ 上两角为直角，下两角圆角由设置控制
```

- 上边缘与屏幕顶部齐平，无间隙
- `border-top-left-radius: 0, border-top-right-radius: 0`
- 下两角圆角由设置面板控制

### 3.2 三态尺寸系统

三种尺寸对应三种交互状态，切换时使用 CSS `transition` 平滑过渡。

| 状态 | 尺寸（宽×高） | 触发方式 | 内容 |
|------|--------------|----------|------|
| **① 最小态** | 140×24 px | 默认显示 / 鼠标离开 1.5s 后 | 时间 + 星期（一行极简） |
| **② 中等态** | 200×50 px | 鼠标悬停 / 滚轮中 | 大号时间 + 完整日期。Phase 2+ 下方加一行系统状态（天气/电量/网络） |
| **③ 最大态** | 520×280 px | 滚轮下翻（Phase 1）/ 滚轮翻到最后一页（Phase 2+） | 设置面板（横向长方形，左侧边栏分类） |

**尺寸过渡曲线**：`cubic-bezier(0.2, 0.8, 0.2, 1)`（先快后慢的自然感）

### 3.3 页面系统（滚轮翻页）

灵动岛在**中等态**时内部是一个多页面容器，滚轮或触控板滚动切换页面。翻到最后一页自动变成**最大态（设置面板）**。

```
中等态页面列表：

  Phase 1（只有 1 页）：
    Page 1: 时间日期（默认页 + 唯一页）
    滚轮下翻 → 直接展开最大态设置面板（因为没有更多页面）

  Phase 2+（多页）：
    Page 1: 时间日期
    Page 2: 天气
    Page 3: 音乐播放
    Page N-1: 系统状态
    Page N: → 滚到这一页，自动展开成最大态设置面板

最大态设置面板：
  侧边栏导航：
    🎨 外观      ← 默认选中
    🖱️ 交互
    📋 内容源
    🔧 高级
    🖥️ 显示器
    ℹ️ 关于
```

### 3.4 设置面板（最大态）

**横向长方形布局，避免竖长形状在三态切换时产生突兀的形态变化。**

```
┌──────────┬──────────────────────────────────────┐
│ 侧边栏    │           右侧内容区                  │
│ 110px    │            ~410px                    │
│          │                                      │
│ 🎨 外观  │  外观设置                              │
│ 🖱️ 交互  │  ┌──────────────┐ ┌──────────────┐  │
│ 📋 内容源 │  │ 样式切换      │ │ 圆角 18px    │  │
│ 🔧 高级  │  └──────────────┘ └──────────────┘  │
│          │  ┌──────────────┐ ┌──────────────┐  │
│ 🖥️ 显示器│  │ 透明度 90%    │ │ 位置 居中    │  │
│ ℹ️ 关于  │  └──────────────┘ └──────────────┘  │
│          │  ┌──────────────┐ ┌──────────────┐  │
│          │  │ 开机自启 开关 │ │ 多显示器 开关│  │
│          │  └──────────────┘ └──────────────┘  │
│          │  ┌──────────────────────────────────┐│
│          │  │ 🎨 主题 / 自定义背景 · 即将推出   ││
│          │  └──────────────────────────────────┘│
└──────────┴──────────────────────────────────────┘
         上边缘（贴边挂角样式）或胶囊圆角（悬浮样式）
```

**关键设计细节**：
- 设置面板本身也有**两种岛样式**（悬浮胶囊版四周圆角 / 贴边挂角版上方直角），跟随用户选择的样式自动切换
- 滚动条：隐藏原生滚动条，使用 3px 宽半透明细滚动条（`::-webkit-scrollbar` 自定义）
- 页面指示器：中等态和最大态顶部显示当前页的小圆点，最后一页为长条形（表示已到设置页）
- 关闭设置面板：鼠标离开 3s 或 `Esc` 键 → 缩回中等态 → 1.5s 后缩回最小态

## 4. 交互设计

### 4.1 状态机

```
                    鼠标进入 (< 100ms)
  ┌───────────┐ ───────────────────────→ ┌───────────┐
  │  ① 最小态  │                          │  ② 中等态  │
  └───────────┘ ←─────────────────────── └─────┬─────┘
                    鼠标离开 (1.5s)             │
                                                │ 滚轮翻到最后一页
                                                ↓
                                          ┌───────────┐
                                          │  ③ 最大态  │
                                          │ 设置面板   │
                                          └─────┬─────┘
                                                │
                                    Esc / 鼠标离开 (3s)
                                                ↓
                                           缩回中等态
```

### 4.2 事件处理

| 事件 | 最小态行为 | 中等态行为 | 最大态行为 |
|------|-----------|-----------|-----------|
| 鼠标进入 | 展开中等态 | — | — |
| 鼠标离开 | — | 1.5s 后缩回最小态 | 3s 后缩回中等态 |
| 滚轮上 | — | 翻到上一页（循环） | 翻到上一页；到第一页后缩回中等态 |
| 滚轮下 | — | 翻到下一页；最后一页展开最大态 | 翻到下一页；到最后一页停留 |
| 单击 | 展开中等态 | — | — |
| Esc | — | — | 缩回中等态 |

### 4.3 动画规范

| 属性 | 过渡时间 | 缓动函数 |
|------|---------|---------|
| 宽度变化 | 280ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| 高度变化 | 280ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| 圆角变化 | 280ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| 背景色/透明度 | 180ms | `ease` |
| 内容淡入淡出 | 150ms | `ease-in-out` |

## 7. 风险与注意事项

| 风险 | 影响 | 缓解 |
|------|------|------|
| Tauri 透明窗口 + WebView2 在某些 Windows 版本上渲染异常 | 窗口显示不全、边缘有黑边 | 开发早期优先测试 Win10 2004 和 Win11，确认透明窗口正常再推进 |
| 贴边挂角样式在多显示器上位置偏移 | 灵动岛可能不在主屏顶部正中央 | Phase 1 只支持主屏；多显示器在 Phase 2 加入 |
| Rust 学习曲线 | 核心窗口层代码量少（~100 行），但需要读懂现有示例 | Tauri 官方透明窗口示例足够参考；若卡住可临时用 Electron 做 Phase 1 验证 |
| Python sidecar 打包进 Tauri 安装包体积增大 | 从 8MB 涨到 ~20-30MB（可接受） | sidecar 作为可选组件，Phase 1 不含 Python |
| 高 DPI 屏幕缩放下窗口位置/尺寸不准 | 灵动岛偏移、模糊 | 启用 Tauri 的 DPI 感知（`dpiAware: true`） |
| 某些全屏游戏会覆盖置顶窗口 | 灵动岛在全屏游戏时看不见 | 可接受；Tauri 窗口使用 `always-on-top = always` 减少覆盖概率 |

## 8. Phase 1 确认事项（已拍板）

以下问题直接给出推荐答案，实施时按此执行，不再逐个询问。

| 问题 | 决定 | 理由 |
|------|------|------|
| 是否需要系统托盘图标？ | **需要**，Phase 1 就加 | 便于右键退出应用、临时隐藏灵动岛、快速打开设置。Tauri 内置托盘 API。 |
| 最小态点击穿透默认值？ | **默认关闭** | 用户可能需要点击最小态触发展开中等态；开启后鼠标事件完全穿透，失去互动能力。用户在设置里可以手动开启。 |
| 设置面板是否需要"确定"按钮？ | **不需要，实时生效 + 自动保存** | 改滑块立刻看到岛的尺寸/圆角/透明度变化，视觉反馈最快。设置变更通过 Tauri Store 实时持久化。 |
| 最大态设置面板是否可拖动？ | **固定位置，不支持拖动** | 灵动岛本身是屏幕顶部的固定位置元素，拖动会打破"贴边"或"居中"的视觉预期。设置面板跟随岛的位置。 |
| 贴边挂角样式 + 系统任务栏重叠怎么办？ | **灵动岛始终在任务栏上方独立显示**（Tauri 窗口层处理） | Windows 任务栏位置是可配置的（默认底部、可移到顶部/左右），灵动岛固定在屏幕顶部，不和任务栏冲突。 |
